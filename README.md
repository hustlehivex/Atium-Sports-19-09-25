# Atium Sports - Premium Sports Website

A modern, premium website for Atium Sports built with React, Vite, TailwindCSS, and Framer Motion. The design is inspired by Samsung, Apple, and STATSports with a sleek, minimal, and professional aesthetic.

## 🚀 Features

### ✨ Design & UI
- **Premium Design**: Clean, minimal aesthetic with lots of whitespace
- **Dark/Light Mode**: Toggle between dark and light themes
- **Responsive Design**: Mobile-first approach with breakpoints for all devices
- **Modern Typography**: Inter and Poppins fonts for clean, professional look
- **Rounded Edges**: Consistent use of rounded-2xl for modern feel
- **Soft Shadows**: Subtle shadow effects for depth and premium feel

### 🎨 Animations & Effects
- **Parallax Scrolling**: Background elements move at different speeds
- **Floating Animations**: Text and elements float as user scrolls
- **Framer Motion**: Smooth page transitions and micro-interactions
- **Hover Effects**: Scale, shadow, and color transitions on interactive elements
- **Staggered Animations**: Elements animate in sequence for visual appeal

## 📦 Installation

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd atium-sports-cursor
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start development server**
   ```bash
   npm run dev
   ```

4. **Build for production**
   ```bash
   npm run build
   ```

## 🎨 Customization

### Colors
The website uses a custom color palette defined in `tailwind.config.js`:
- **Primary**: Blue tones for main brand color
- **Secondary**: Gray tones for text and backgrounds
- **Accent**: Red tones for highlights and CTAs

### Fonts
- **Display**: Poppins for headings and titles
- **Body**: Inter for body text and UI elements

### Animations
All animations are configured in TailwindCSS and use Framer Motion for complex interactions.

## 📱 Responsive Breakpoints

- **Mobile**: < 640px
- **Tablet**: 640px - 1024px
- **Desktop**: > 1024px
- **Large Desktop**: > 1280px
